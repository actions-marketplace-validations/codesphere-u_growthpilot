Everything you need to run GrowthPilot locally, wire its stdio MCP server into AI coding agents, or gate every pull request in CI.

Quickstart AI Agents & MCP GitHub Actions Frameworks CLI Flags

1. Quickstart CLI

Requires Python 3.10+ only — zero third-party packages installed.

Install globally or run once via uv 
uv tool install git+https://github.com/codesphere-u/growthpilot
growthpilot ./my-app
growthpilot https://yoursite.com --fix
Ephemeral one-liner (uvx) 
uvx --from git+https://github.com/codesphere-u/growthpilot growthpilot .

2. AI Coding Agents & MCP Server

Expose 6 native tools (audit_project, analyze_copy_cro, generate_geo_seo_pack, generate_launch_kit, generate_programmatic_seo, apply_marketing_fixes) over stdio.

Install as an AI coding skill 
npx skills add codesphere-u/growthpilot
mcp_config.json (Claude Code, Cursor, Antigravity, Codex) 
{
  "mcpServers": {
    "growthpilot": {
      "command": "growthpilot",
      "args": ["--mcp"]
    }
  }
}

3. GitHub Action & SARIF 2.1.0 Quality Gate

Fail builds below a threshold or upload SARIF findings directly to GitHub Security alerts.

.github/workflows/growth-audit.yml 
- uses: codesphere-u/growthpilot@v1
  with:
    target: .
    site-url: https://yoursite.com
    min-score: 85
    fail-on: high
    sarif-file: growthpilot.sarif

4. Framework Asset Placement

Next.js (App Router)

Place llms.txt and llms-full.txt under public/. If app/robots.ts or app/sitemap.ts exists, --fix automatically skips overwriting dynamic routes.

Static HTML / Astro / Vite

Keep llms.txt, robots.txt, sitemap.xml, and manifest.webmanifest at the public site root next to index.html.

5. CLI Flags Reference

Flag Default Behavior
target . Local directory path or public http(s):// URL
--live URL off Fetch live HTML, subpath GEO files & Next.js FAQ chunks
--site-url URL auto Override canonical base URL when auditing codebases or staging
--fix false Non-destructively scaffold missing SEO & GEO files
--output-dir DIR growthpilot-out Directory where all 12 generated artifacts are written
--min-score N 0 Exit with code 1 if score drops below N
--sarif FILE off Emit SARIF 2.1.0 report for GitHub Code Scanning
--mcp false Start zero-dependency stdio Model Context Protocol server
