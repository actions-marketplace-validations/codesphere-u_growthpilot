Getting Started

Download & Install

v1.4.3

Install CLI

Requires Python 3.10+ only — zero third-party packages installed. 

uv tool install git+https://github.com/codesphere-u/growthpilot

First Audit

Point GrowthPilot at any project directory or live URL. Both modes run locally and produce identical 100-point scoring.

  1. Repository scan — reads routes, metadata, framework conventions, and copy without running external builds.
  2. Live URL audit — fetches HTML, subpath GEO endpoints (llms.txt, robots.txt), and client JS chunks for FAQ answers.

Choosing a Mode

On first run, choose whether to audit safely in read-only mode or write missing SEO and GEO files directly to disk.

growthpilot . --site-url https://yoursite.com
growthpilot https://yoursite.com --fix

Shortcuts & Outputs

Quick commands for day-to-day shipping across search engines, AI answer engines, and pull request checks.

Command Action
growthpilot . Grade current directory across all 18 rules in < 1s
growthpilot URL --fix Scaffold missing llms.txt, robots.txt, and sitemap.xml
growthpilot --mcp Start stdio Model Context Protocol server with 6 tools
growthpilot --min-score 100 Exit with code 1 in CI if score drops below 100

1. Target & Live URLs

Pass either a filesystem directory (., ./website, ./apps/web) or an https:// URL. When scanning a local repo alongside a production deployment, combine both flags with --live. 

growthpilot ./website --live https://codesphere-u.github.io/growthpilot --sarif growthpilot.sarif

2. Quality Gates

Use --min-score N or --fail-on high to block deploys when canonical tags, llms.txt, or social previews regress. Passing --fix writes missing static files strictly without overwriting existing files or dynamic Next.js route generators.

3. All CLI Flags

Flag Default Behavior
target . Local project directory or public http(s):// URL
--live URL off Fetch live HTML, subpath GEO files & Next.js FAQ chunks
--site-url URL auto Override canonical base URL when auditing codebases or staging
--fix false Non-destructively scaffold missing SEO & GEO files
--output-dir DIR growthpilot-out Directory where all 12 generated artifacts are written
--min-score N 0 Exit with code 1 if score drops below N
--sarif FILE off Emit SARIF 2.1.0 report for GitHub Code Scanning
--mcp false Start zero-dependency stdio Model Context Protocol server

1. stdio Config

Start GrowthPilot’s built-in stdio Model Context Protocol server with zero external dependencies using growthpilot --mcp. 

{
  "mcpServers": {
    "growthpilot": {
      "command": "growthpilot",
      "args": ["--mcp"]
    }
  }
}

2. 6 Native Tools

Tool Name Purpose

3. Tool Arguments

Every MCP tool accepts plain JSON arguments (path, site_url, live_url, apply_fixes) and returns structured JSON findings with remediation snippets.

1. PR Quality Gate

Prevent broken canonical tags, missing llms.txt indexes, or slop-heavy hero copy from merging to main. 

- uses: codesphere-u/growthpilot@v1
  with:
    target: .
    site-url: https://yoursite.com
    min-score: 85
    fail-on: high
    sarif-file: growthpilot.sarif

2. SARIF 2.1.0 Alerts

Pass sarif-file: growthpilot.sarif and upload it via github/codeql-action/upload-sarif@v3 to annotate pull requests inline in GitHub Code Scanning.

3. Action Inputs

Input Default Description
target . Repository path or live deployment URL

fail-on none Fail on severity threshold (critical, high, medium)
sarif-file empty Path to write SARIF 2.1.0 diagnostics

Next.js App Router

Place llms.txt and llms-full.txt inside public/. If dynamic route files like app/robots.ts or app/sitemap.ts exist, --fix detects them automatically and skips static overrides.

Static HTML, Astro & Vite

Keep llms.txt, llms-full.txt, robots.txt, sitemap.xml, and manifest.webmanifest at your public web root directly alongside index.html. GrowthPilot automatically discovers all sub-pages and checks every page for single-<h1>, canonical, title, and description tags.

Python & Node APIs

FastAPI, Flask, Express, and CLI repositories are automatically classified so Schema.org SoftwareApplication or Organization graphs match your package metadata.

Discovery & GEO

  • llms.txt — Structured Markdown site index following llmstxt.org.
  • llms-full.txt — Complete context pack for Claude, ChatGPT, Perplexity, and Gemini.
  • robots.txt — Explicit Allow: / rules for GPTBot, ClaudeBot, and PerplexityBot.
  • sitemap.xml — Clean XML sitemap covering every discovered route.

Schema & Social

  • SEO_SCHEMA.jsonld — Validated Schema.org @graph tailored to your product archetype.
  • HEAD_TAGS.html — Copy-paste <title>, canonical, OpenGraph, and Twitter card tags.
  • manifest.webmanifest — App name, short name, theme colors, and icon definitions.

Playbooks & Reports

  • AUDIT_REPORT.md — Score breakdown and prioritized fixes sorted by points recovered.
  • growth-summary.json — Machine-readable audit payload for scripts and dashboards.
  • LAUNCH_PLAYBOOK.md, PROGRAMMATIC_SEO.md, and CRO_COPY_REWRITES.md.

Subpath GitHub Pages

When deploying to a project path such as https://username.github.io/repo/, pass the full subpath URL to --site-url. GrowthPilot checks both domain root and project subpath for llms.txt, llms-full.txt, and robots.txt.

Next.js Client FAQs

Client-only accordion components sometimes hide FAQ answers inside hydration JavaScript chunks while omitting them from initial SSR HTML. GrowthPilot inspects compiled chunks on --live scans and flags MKT009 if search and AI bots receive questions without answers.

Slop Word Flags (MKT015)

Visible UI copy and meta descriptions trigger MKT015 if inflated AI filler adjectives or vague hype phrases appear instead of concrete facts. Replace vague claims with real metrics, file counts, latency numbers, and direct active verbs.

Origin Story

GrowthPilot started with a simple observation: small engineering teams build great software and then ship invisible landing pages because serious SEO and AI-search audits sit behind $99–$499 monthly dashboards.

Project Goals

Rather than another black-box marketing dashboard, GrowthPilot gives builders an inspectable, local, zero-dependency CLI and MCP server that runs in under a second right next to your tests and linter.

Under the Hood

  • Pure Python 3.10+ standard library — zero pip dependencies and zero network calls during local repo scans.
  • 18 transparent rules weighted across 6 balanced pillars totaling 100 points.
  • Outputs both clean developer diagnostics (SARIF, JSON) and ready-to-deploy web files (llms.txt, JSON-LD, sitemaps).
