# Conversion Rate Optimization (CRO) & Anti-Slop Copywriting

## 1. Above-the-Fold Hero Formula

Every high-converting landing page or repository README must answer three questions within 5 seconds:
1. **What is it?** (Concrete category anchor, not abstract poetry)
2. **Who is it for & what painful problem does it kill?** (Specific job-to-be-done)
3. **How fast do I get value?** (Zero-friction CTA or 1-command quickstart)

### Proven Copy Frameworks Built Into GrowthPilot
- **PAS (Problem -> Agitate -> Solve)**: Name the painful status quo, show the cost of ignoring it, present the deterministic fix.
- **JTBD (Jobs-To-Be-Done)**: *"When [situation], I want to [action], so I can [measurable outcome] without [pain point]."*
- **Before / After Bridge**: Contrast the old 6-tool manual workflow against the 1-command automated workflow.

---

## 2. Banned AI-Slop & Weasel Words (`MKT015`)

Buyers and developers immediately bounce when they read generic LLM filler:
- **Never use**: `revolutionary`, `game-changing`, `unleash`, `unlock the power`, `seamlessly`, `next-generation`, `cutting-edge`, `elevate`, `tapestry`, `delve`, `synergy`, `supercharge`, `paradigm shift`, `world-class`, `all-in-one magic`.
- **Replace with**: Exact latency (`12ms`), exact dependency count (`0 dependencies`), exact standards (`SARIF 2.1.0`, `MCP JSON-RPC 2.0`), and verifiable commands.
