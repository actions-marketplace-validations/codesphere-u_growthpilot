# Zero-to-One Multi-Channel Launch & Programmatic SEO Playbook

## 1. Coordinated Launch Sequence

1. **Hacker News (`Show HN`)**:
   - Title format: `Show HN: <Name> – <Factual 1-line description without adjectives>`
   - Body rules: Explain the technical mechanism, why existing tools failed, how to try it immediately without signup (`uvx` / live demo), and invite architectural critique.
2. **Product Hunt**:
   - Tagline under 60 chars focused on outcome.
   - Maker's first comment structured as: Problem -> Why we built it -> 3 killer features -> Free/open-source access.
3. **Reddit Organic Distribution**:
   - Lead with a deep technical post-mortem or benchmark story; place the repo link at the bottom as reference.
4. **X / LinkedIn Founder Thread**:
   - Hook (concrete metric or painful bug) -> 30-second visual demo -> 4 bullet takeaways -> CTA link in reply.

## 2. Programmatic SEO Hub-and-Spoke Matrix

Instead of writing generic blog fluff, build high-intent bottom-of-funnel pages:
- **Comparison Pages**: `<Product> vs <Alternative>` (honest feature matrix + when to choose each)
- **Alternatives Pages**: `Best Open-Source <Category> Alternatives in 2026`
- **Use-Case Blueprints**: `How to <Job-to-be-Done> in <Framework>` (Next.js, FastAPI, Astro, Shopify, Claude Code, Cursor)
